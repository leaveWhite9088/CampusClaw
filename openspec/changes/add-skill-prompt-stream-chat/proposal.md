# Change: add-skill-prompt-stream-chat

## Why

第 4 课已能用一句话检索本班材料并标出出处（单次问答 `/api/ask`）。第 5 课把它升级为**解题助手**：教师维护提示词与「解题引导」技能，学生新建会话连续追问，回答以 SSE 流式逐段返回——提示词、技能、知识库三者参与同一次回答。同时补齐工程化配套：OpenAPI 文档（Swagger 页面可试调）与 `apitest/` 接口测试。

## What Changes

- **班级提示词**：教师可为全班编写并保存提示词（规定助手是谁），从下一轮对话生效；学生只读不可修改。
- **解题引导技能**：教师维护至少一条「解题引导」技能（名称、简介、完整指令），可启用/停用；启用时引导思路并引用本班材料出处、不直接给最终答案；停用后同一问题的回答方式应明显不同；学生不能开关技能。
- **会话与 SSE 流式回答**：学生可新建会话、查看自己的会话列表与历史消息；发送消息走 `POST /api/conversations/<id>/messages`，以 `text/event-stream` 逐段推送回答；回答前先检索本班知识库（混合检索前 4 条），有命中标出处、无命中返回固定文案且不调用生成模型；提问与回答按会话保存。
- **沿用第 4 课语义**：本班检索、班级取自凭证、跨班表现为无命中、Bearer 与 Cookie 双凭证，全部不变。
- **OpenAPI 文档**：提供 `openapi.json`（路径、入参出参、错误码、是否需要登录）与浏览器可打开的 Swagger 试调页面。
- **接口测试**：新增 `apitest/`（一接口一脚本、按 URL 组织）、`run_all.py` 一键执行并生成 HTML 报告（报告不入库）；用例核对返回内容与数据库一致性；覆盖登录、检索、提示词/技能、创建会话并发送一条消息。

## Capabilities

### New Capabilities

- `assistant-chat`：班级提示词维护、解题引导技能维护与开关、会话管理与 SSE 流式回答、回答编排（提示词+技能+检索）、接口测试与 API 文档的可验收行为。

### Modified Capabilities

（无——`auth-upload` 与 `knowledge-retrieval` 行为不变，本 change 在其上编排。）

## Impact

- 数据层：新增 `class_prompts`、`conversations`、`messages` 表；扩展 `skills` 表（简介、指令、启用开关）。
- 服务层：新增提示词/技能/会话三组 API 与 SSE 推送；对话编排把提示词、启用技能指令、检索切片组装给对话网关。
- 页面：教师设置页（提示词 + 技能），学生解题助手页（会话列表 + 流式对话 + 出处）。
- 文档：仓库内 `openapi.json` 与 `/swagger` 页面。
- 测试：`apitest/` 目录与 `run_all.py`；报告输出目录 gitignore。

## Non-goals（非目标）

- 不做错题讲解、作业批改等其余技能；技能不文件夹化、不做渐进式披露（只有一个技能，启用即整段注入）。
- 不做 MCP、子代理编排；检索由服务端流程固化，不交给模型临场决定。
- 不做异步队列、消息重发与编辑、会话共享。
- 不做 Function Calling：技能开关由教师控制，模型不自主选择工具。
