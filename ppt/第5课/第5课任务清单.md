# 第 5 课：任务清单

> 来源：北京大学《互联网软件开发技术与实践》第 5 课课程任务清单页面（HTML 整理为 Markdown）

提示词、AI 技能与流式会话 · 按下面清单完成，可对照 [系统原型](https://devops.hello1023.com/week05/) 理解效果

### 一、功能（解题助手）

- [ ] 教师能设置提示词，维护至少一条「解题引导」类技能（只引导、不直接给最终答案）。
- [ ] 学生能新建会话，提问后**流式**看到回答；回答前先检索本班知识库，并能看到引用出处。
- [ ] 继续沿用第 4 课：本班检索、单次问答；跨班访问与「没有这条数据」表现一致。
- [ ] 登录后用 Bearer 令牌访问接口（与 Swagger 里写的一致）。

### 二、Swagger 文档

- [ ] 提供 OpenAPI 描述（路径、入参出参、错误码、要不要登录）。
- [ ] 浏览器能打开 Swagger 页面，并能对照文档试调主要接口。

参考：[Swagger](https://devops.hello1023.com/week05/swagger/) ·
[openapi.json](https://devops.hello1023.com/week05/openapi.json)

### 三、接口测试

- [ ] 在仓库里建 `apitest/`：一个接口一个脚本；目录按 URL 组织，例如 `cases/api/login/POST.py` 表示 `POST /api/login`。
- [ ] 写 `run_all.py`，能一键跑完并生成 HTML 报告（报告不要提交到 Git）。
- [ ] 不只对状态码：还要核对返回内容和数据库里是否一致。
- [ ] 至少覆盖：登录、检索、提示词/技能、创建会话并发送一条消息。

课堂上的补充要求以课件为准；密钥只放在本机 `.env`，不要提交到 Git。
