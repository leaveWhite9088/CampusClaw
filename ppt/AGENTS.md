# ppt 目录规则

本目录存放课程课件的 Markdown 整理版，只要信息内容，不要原始 HTML 格式。

## 目录结构

- 每课一个子目录，命名为 `第N课`（如 `第2课`、`第3课`）。
- 课件正文统一为 `第N课.md`，与子目录同名。
- 有信息量的截图放 `第N课/assets/`，正文用相对路径引用（如 `assets/xxx.png`），保证目录整体移动后引用仍有效。

## 课件整理要求

- 课件以**简洁**为第一原则：只保留正文信息——标题、段落、列表、表格、代码块。
- 丢弃网页格式与装饰：导航栏、页脚、翻页按钮、HTML 属性残留等一律不要。
- 不要封面风景图等纯装饰图片；截图只保留能传递信息的（如操作实录、效果对比）。
- 来源为 HTML 课件站时，转成单个 Markdown 文件后删除原 HTML/CSS/JS 文件。
- 表格转 Markdown 表格，代码/命令用 ``` 围栏代码块并标注语言。
- 文件开头用引用块标注来源，格式：`> 来源：北京大学《互联网软件开发技术与实践》第 N 课课件（HTML 整理为 Markdown）`。
