# 第 6 课：任务清单

> 来源：北京大学《互联网软件开发技术与实践》第 6 课课程任务清单页面（HTML 整理为 Markdown）

MCP 与工具接入 · 按下面清单完成，可对照 [系统原型](https://devops.hello1023.com/week06/) 理解效果

### 一、自建 MCP 服务器（`mcp-server/`）

- [ ] 在本课仓库内新增 `mcp-server/` 目录（与主应用**同仓**，由 `docker-compose.yml` 一并构建启动；不另开第二个 Git 仓库）。
- [ ] 提供 `POST /mcp`（JSON-RPC 2.0）与 `/health`；Bearer 令牌从环境变量读取（如 `MCP_AUTH_TOKEN`），**不进 Git、不进镜像层、不进前端**。
- [ ] 至少实现 `initialize`、`tools/list`、`tools/call`；无令牌或令牌错误返回 401，非法请求返回可读的 JSON-RPC 错误。
- [ ] 至少暴露 **2 个工具**（名称符合主机侧引用规则：小写字母开头、无连字符）。示范仓为 `formula_hint`、`unit_convert`；你可换成与本班场景更贴切的实现，但须能在 `tools/list` 里被发现并在 `tools/call` 里返回文本结果。
- [ ] Compose 中 MCP 服务与 API 同网互通；主应用通过 Base URL（如 `http://mcp-demo:8090`）连到自建的 MCP 服务，而不是只 mock 主机侧逻辑。

对照：`project-src/week06-harness/mcp-server/`（课程示范，可 fork 后改工具语义）

### 二、主机侧登记与工具发现

- [ ] 教师能登记本班 MCP 服务器（名称、Base URL）；**Bearer 令牌只保存在 CampusClaw 服务端**，接口响应不得带回密钥。
- [ ] 教师能「连接」服务器：完成握手并执行 `tools/list`，把工具清单缓存到本系统；「断开」后清空缓存且不可再调用。
- [ ] 连接失败时有明确错误提示，且不阻断第 5 课已有的检索与流式对话主路径。
- [ ] 登记 Base URL 指向你在 Compose 里自建的 MCP 服务；连接成功后能在管理界面看到你在 `mcp-server` 里实现的工具名。

### 三、技能绑定与鉴权调用

- [ ] 技能文件「工具」除 `knowledge_search` 外，支持 MCP 引用格式 `工具名@服务器名`（例如 `formula_hint@campus-tools`）。
- [ ] 保存技能时校验：绑定的 MCP 工具必须属于本班、服务器已连接且已通过发现列入缓存；否则拒绝保存。
- [ ] 学生提问命中带 MCP 工具的技能时，服务端带令牌调用远端 `tools/call`；结果作为**数据**拼进用户消息，不当作系统指令。
- [ ] 流式响应 `meta` 中能看见 `tool_calls`（含工具引用与状态）；未连接或越权调用记为 `denied`，不静默成功。
- [ ] 继续沿用第 3–5 课：班级只取自会话、跨班 404 一致、Bearer 鉴权。

### 四、审计与 Swagger

- [ ] 教师能查看本班 MCP 工具调用审计（至少含 `tool@server`、状态、用户与时间）。
- [ ] 补充 MCP 相关 OpenAPI 注解并生成文档；浏览器能打开 Swagger 试调 connect / tools / 技能保存等主要接口。

参考：[Swagger](https://devops.hello1023.com/week06/swagger/) ·
[openapi.json](https://devops.hello1023.com/week06/openapi.json)

### 五、接口测试（建议）

- [ ] 在 `apitest/` 为 MCP 管理接口增加用例（登记、连接、列出工具、断开；非教师应 403）。
- [ ] 至少一条用例：连接演示 MCP → 注册含 `formula_hint@…` 的技能 → 会话提问 → 审计表出现 `ok` 记录。
- [ ] 用 `run_all.py` 生成 HTML 报告（报告不要提交到 Git）。

### 六、验收证据（自查）

- [ ] 单独验证 `mcp-server`：`/health` 正常；带 Bearer 的 `tools/list` 返回你实现的工具；`tools/call` 能拿到文本内容。
- [ ] 主机侧：连接 MCP → 发现工具 → 技能绑定并在对话中触发 → 审计含服务器与工具标识。
- [ ] 断开后：同一技能不再能成功调用 MCP（保存/调用路径至少一处明确拒绝）。
- [ ] 主机 `.env` 里的 MCP 令牌与 `mcp-server` 环境变量一致；令牌未出现在前端、Git 或镜像中。

在第 5 课仓库上增量实现：主应用仍是一个 CampusClaw，另加同仓的 `mcp-server/`。课堂补充要求以 第 6 课课件 为准；密钥只放在本机 `.env`。
