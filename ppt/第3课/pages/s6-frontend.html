6 前端页面

演示 change 的前端以 delta spec R9 + R10 为准：行为与安全见 R9；品牌色、主题、双视图、本班搜索、命令面板、上传进度、toast 与 Markdown 见 R10。本页三个步骤与 tasks §7（含 7.8–7.16）一一对应。

每步按同一顺序展开：知识点 → 其他可行方案与选择依据 → 本步要核对 → 动手要做。“怎么查”一列给出三处证据：规约读哪条、代码搜什么、运行做什么；发现不一致，先补规约或改实现。全课汇总见 实现方案核对总表。

1路由与身份恢复

刷新页面后本地状态清空，身份一律以 /api/me 为准。

知识点

身份以 /api/me 为准

刷新页面后本地内存清空。用服务端会话换回角色与班级。localStorage 中的 role 可被修改，不能作为授权依据。

其他可行方案与选择依据

方案 要点 本课如何取舍
前端本地硬编码 role 切换器 方便演示越权。 否决。角色只来自 /api/me。

本步要核对

核对项 本迭代应采用 怎么查（规约 / 代码 / 运行） 自检
刷新页面后如何恢复身份？ 用 /api/me 重新确认会话；本地内存清空不作为依据。 规约：是否写明刷新后的身份恢复方式
代码：看应用初始化逻辑
运行：刷新页面与重开标签页各试一次

动手要做

  • 登录页提交 /api/login；失败只显示统一错误，用通知或页内提示反馈。
  • 刷新时用 GET /api/me 确认会话；有效则进入材料页，无效则回登录页。
  • 收到 401 时清空状态并返回登录页。登出调用 /api/logout。

2界面不承担访问控制

不渲染入口只降低误操作概率；绕过界面仍必须失败，401 / 403 / 404 的界面处理要与服务端语义一致。

知识点

界面不是访问控制

不渲染上传按钮、不提供其他班级的链接，只降低误操作概率。攻击者可以直接用 curl 携带 Cookie 调用接口。验收必须包含绕过界面的失败路径。

其他可行方案与选择依据

方案 要点 本课如何取舍
服务端渲染（模板或 Next.js SSR，Server-Side Rendering） 首屏渲染快，利于 SEO。 可行。当前需求是 Vite SPA + 同源 /api。不要为 SSR 把会话逻辑只放前端。

本步要核对

核对项 本迭代应采用 怎么查（规约 / 代码 / 运行） 自检
上传入口依据什么显示？ 依据 /api/me 返回的角色，不依据本地存储中的角色。 规约：是否写明身份来源
代码：搜 localStorage 中是否存有 role
运行：手工改本地存储的 role，看入口是否变化
401 / 403 / 404 的界面处理是否与服务端语义一致？ 401 清状态回登录页；403 与 404 按服务端语义提示，不改变语义。 规约：是否写明前端对失败状态的处理
代码：搜前端错误分支
运行：分别触发三种响应，观察界面反馈

动手要做

  • 材料列表请求 /api/materials；详情与下载走鉴权接口。
  • 上传入口是否显示，取决于 /api/me 返回的角色。学生界面不提供上传；绕过界面仍须返回 403。

3材料页：展示、搜索与体验

格式化展示不等于把原文当 HTML 注入；搜索只在本班材料范围内，不是跨班全文检索。

知识点

Markdown 展示的风险

渲染时使用 Markdown 库的默认转义策略，不执行材料中的脚本。搜索只在本班数据范围内过滤，不是跨班级全文检索。

体验与安全分层

深浅色、网格视图、命令面板、进度条服务于可用性。它们不改变 401 / 403 / 404 的语义。

其他可行方案与选择依据

方案 要点 本课如何取舍
Tailwind CSS / 组件库（如 Ant Design、Element Plus） 开发效率高。 可行。需求写的是原生 CSS 设计系统；换成 UI 库须在规约中说明，且不能替代鉴权。
Markdown 转 HTML 后存库 读取详情更快。 本课存原文、读时渲染，避免入库时注入。渲染须转义。

本步要核对

核对项 本迭代应采用 怎么查（规约 / 代码 / 运行） 自检
Markdown 渲染是否转义？ 使用库的默认转义策略，不执行材料中的脚本。 规约：是否写明渲染安全要求
代码：搜直接注入 HTML 的用法
运行：上传含 script 标签的 .md，观察是否被执行
搜索范围是否限于本班？ 本班材料范围内筛选标题或正文，不是跨班全文检索。 规约：是否写明搜索范围
代码：看搜索请求携带的参数
运行：用 B 班材料标题在 A 班搜索，应无结果

动手要做

与 R9 + R10 + tasks §7 一致（必做）：

  • 列表 /api/materials（R9.2）；401 清状态回登录（R9.5）。
  • 上传入口仅 teacher，依据 /api/me（R9.3、R2.5）；XHR 上传进度（R10.7、tasks 7.13）。
  • 详情 /api/materials/{id}；下载 .../file（R9.4）；.md 用 GFM（R10.9）。
  • 本班搜索、列表/网格、⌘/Ctrl+K 命令面板、深浅色主题、toast、响应式（R10、tasks 7.8–7.16）。

把否决理由用自己的话写进 design / 迭代说明；原文照录本表不算 ADR。

向 Harness 核对的参考提问

可直接复制到会话中使用。要求它逐项给出证据（文件与行号、命令与输出），找不到就明说、不许推测；回答只作线索，勾选前仍须亲自运行 verify 复核。

  1. 刷新页面后身份如何恢复？找到调用身份接口的代码；是否存在把角色缓存在 localStorage 并直接采信的逻辑？
  2. 上传入口的显示依据是什么？绕过界面直接调用上传接口时服务端行为是什么？据此说明隐藏按钮为什么不算权限控制。
  3. Markdown 渲染使用什么库、默认是否转义 HTML？用一段含 <script> 的材料内容实测渲染结果并贴出。
  4. 401、403、404 三种响应在前端分别呈现什么？逐一核对与服务端语义是否一致。
