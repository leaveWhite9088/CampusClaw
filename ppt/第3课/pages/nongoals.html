1为什么必须写 Non-goals

不写不做项，实现最容易在边界缺失处膨胀；越界功能往往能追溯到规约没有写“不做”。

知识点

范围蔓延

Harness（AI 编码代理）最容易在 Non-goals（明确不做项）缺失时额外生成聊天界面、JWT、RAG。把不做项写进规约，为 Apply 阶段提供了硬性约束。

其他可行方案与选择依据

方案 要点 本课如何取舍
本课做 RAG / 对话助手 产品形态看起来更完整。 否决。隔离与入库尚未稳定时，问答会造成跨班数据泄露。第 4 课再扩展检索。
本课接校园 SSO（Single Sign-On，单点登录） 账号登录体验统一。 否决。应先掌握自己签发会话、登出与 RBAC 的实现。方案对照见认证方案页。
本课上 K8s（Kubernetes，容器编排平台）多副本 更接近生产环境。 否决。进程内限流与会话在多副本下会出错。标准启动是单实例 Compose。

2越界实现的识别与自查

知识库只存可查正文；发现越界功能时先补规约，而不是先改文档迁就代码。

知识点

知识库不等于问答

本课只存可查正文。列表快捷搜索可以做。向量化、RAG、作业流程会改变数据模型和验收，不要提前做。

JWT 不是本课认证方案

当前需求写明服务端 Session Cookie。把 Bearer token 写进前端再当授权依据，属于范围蔓延，也把租户标识交回客户端。

Non-goals 属于 proposal.md。发现越界实现时，先用 /opsx-update（技能 openspec-update-change）把不做项与边界补进 change 的 proposal.md 与 delta，再删代码。只删代码不改规约，下一次生成还会把它补回来。

本步要核对

核对项 本迭代应采用 怎么查（规约 / 代码 / 运行） 自检
代码里是否出现越界实现？ 无 JWT / OAuth、无向量库、无对话接口。 规约：不做项清单
代码：搜依赖清单、路由与前端页面
运行：逐个访问新增页面，确认是否属于本迭代范围
知识库是否只存可查正文？ 是，未提前向量化，为下一迭代预留。 规约：知识库在本迭代的定位
代码：看 knowledge_entries 表结构
运行：查库确认只有正文类字段，无向量列

3本迭代不做的清单

清单要落到本人规约的 Non-goals 一节，提交前逐条自查。

本迭代必须验收的 Web（spec R9 + R10）

  • 行为与安全：两页、GET /api/me、鉴权 API、401 回登录、防脚本（R9）。
  • 视觉与交互：北大红、深浅色、响应式、列表/网格、本班搜索、⌘/Ctrl+K 命令面板、上传进度、toast、Markdown GFM（R10）。

动手要做：Non-goals 写入本人 proposal

  • 知识库问答、向量检索、RAG。本课知识库只存可查正文。
  • 对话助手、作业布置与批改、成绩与错题本。
  • JWT / OAuth / SSO。登录态用服务端会话 Cookie，不要用 localStorage 里的 Bearer token。
  • 注册改密、多校多租户、验证码或邮箱短信登录。
  • PDF / Word / 图片解析，以及在线预览与编辑。
  • Kubernetes、CI、公网域名、HTTPS 证书、多副本高可用。当前单实例 Compose。
页面再完整，也不能代替服务端鉴权。用 curl 仍能绕过班级隔离或让学生上传成功，本课不算完成。

为什么本迭代不做平台超级管理员

产品完整形态里一定会有这个角色（跨班运维、账号与班级管理），但它在任何一次迭代里都应当是单独设计的一项，而不是顺带做出来的：
  • 它与本迭代的隔离验收直接冲突。超级管理员天然跨班，而本迭代把“跨班访问与记录不存在返回同一个 404”作为隔离成立的证据。先放进一个可以合法跨班的角色，那个 404 就不再能作为证据。
  • 它的风险点与教师/学生完全不同。教师与学生之间的越权是“同角色、不同班级”；超级管理员是系统内唯一允许跨班的角色，需要的是操作审计、二次确认与最小化授权，属于另一组规约。
  • 所以正确顺序是：先让隔离可判定并验收通过，再单独开一次变更引入它。表结构可以预留字段，但本迭代不验收、不实现入口。
本迭代要做的只有一件事：把它写进 proposal.md 的 Non-goals。不写，Harness 很可能在未声明的情况下生成一个管理员入口或一条可跨班的查询分支——即便界面上看不见，它也已经绕过了隔离。
可直接写入本人 Non-goals 的表述（可按自己的话改写）：
- 平台超级管理员：产品完整形态里必然存在的角色，本迭代不做。它跨班可见，会与班级隔离的验收冲突；留待隔离稳定后单独开一次变更，设计其越权路径与操作审计。

把否决理由用自己的话写进 design / 迭代说明；原文照录本表不算 ADR。
