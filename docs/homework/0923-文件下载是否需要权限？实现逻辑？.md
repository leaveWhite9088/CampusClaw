# 0923-文件下载是否需要权限？实现逻辑？

> 分析对象：CampusClaw 学期项目（本仓库）真实实现
> 相关代码：`app/materials.py`（download 路由）、`app/db.py`（查询）
> 规约依据：`openspec/changes/add-auth-rbac-class-knowledge/specs/auth-upload/spec.md`「材料文件下载」Requirement

## 一、结论：需要权限，且是两层

文件下载**必须登录**，并且**只能下载本班材料**。匿名用户和跨班用户在服务端都会被拒绝，得不到任何文件内容。

## 二、实现逻辑（`GET /materials/<id>/download`）

```
请求 GET /materials/<id>/download
        │
        ▼
① 登录校验（login_required）
   无会话 → 页面请求 302 重定向登录页 / API 请求 401，响应不含文件内容
        │
        ▼
② 按 ID 查材料记录（SELECT by id，不带班级条件，以便识别越权）
   记录不存在 → 404
        │
        ▼
③ 班级隔离校验（服务端，不靠前端隐藏按钮）
   记录 class_id ≠ 会话 class_id → 403，响应不含他班内容/标题/路径
        │
        ▼
④ 下发文件
   · 教师上传的材料：按 DB 中 file_path 从 uploads/ 目录读取原文件，
     路径做分隔符归一化 + commonpath 校验防目录逃逸，
     Content-Disposition: attachment 触发浏览器下载
   · 预置种子材料（无落盘文件）：取知识库 knowledge_entries 正文，
     生成等价的 .md 附件返回
```

关键点：**身份与班级都不信客户端**——会话 Cookie 验签后取出 `class_id`，下载与否由服务端比对决定；文件路径经 `commonpath` 校验，防止 `../` 目录逃逸读到 uploads 之外的文件。

## 三、实测验证（截图证据对应）

| 场景 | 预期 | 实测 |
| --- | --- | --- |
| 未登录直接访问 `/materials/1/download` | 拒绝 | **302 重定向登录页**，响应体为 Redirecting 页面，无文件内容 |
| 学生 A1（A 班）下载 B 班材料 `/materials/2/download` | 拒绝 | **403 Forbidden**，无 B 班内容 |
| 教师 A 下载本班材料 `/materials/1/download` | 允许 | **200**，`Content-Disposition: attachment`，内容正确 |
| 学生 A1 下载本班材料 | 允许 | **200**（学生只读，但可读/下载本班内容） |

## 四、一句话回答

下载需要权限：未登录拿不到文件（302/401），跨班也拿不到（403）；身份识别沿用登录时下发的签名会话 Cookie，班级边界在服务端查询层强制执行。
